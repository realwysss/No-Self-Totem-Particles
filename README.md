# No Self Totem Particles

hides your own totem of undying pop particles so they do not block your screen. other players' totem particles still show.

client side fabric mod, no settings.

made by ways, discord: waystobe

## download

`NoSelfTotemParticles-ALL-VERSIONS.jar` on the releases page. it is built with intermediary names, one jar for the fabric versions that share them.

## source

`src` has the code and `res` has the resources. the mixin is tiny: it cancels the totem particle when it was added for your own player.
